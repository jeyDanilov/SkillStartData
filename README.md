These JSON files are used as mock API endpoints for the SkillStart Android app during development.
 
 Purpose
Provide a simple, static API endpoint for testing and development

Allow the Android app to fetch data without a real backend

Enable offline-first and caching logic in the main SkillStart project

Support Retrofit integration during development

 Contents
data.json — main dataset used by the SkillStart app

Additional JSON files for testing and UI previews

 Hosting
The JSON files are served via GitHub Pages, making them accessible as public API endpoints.

Example:
https://jeyDanilov.github.io/SkillStartData/data.json
